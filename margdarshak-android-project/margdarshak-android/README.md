# Margdarshak Android App (SIH26241 — MSDE)

## Direct APK Installation (Fastest)
1. Download `margdarshak.apk` directly onto your Android smartphone.
2. Tap `margdarshak.apk` in your Downloads notification or File Manager.
3. If prompted by Android, allow **"Install unknown apps"** for your browser/file manager and tap **"Install anyway"** on Play Protect (since it is self-signed for SIH demonstration).
4. Open **Margdarshak** from your home screen or app drawer!

## Features Included Offline in the APK
- **Bilingual UI (English + हिन्दी)** with instant language switching
- **Floating Multilingual AI Career Sahayak Chat Box** at the bottom-right trained on all 4 official data sources (`SRC-NCVET-NSQF`, `SRC-DGT-ITI`, `SRC-PMKVY-EST`, `SRC-NSDC-DEMO`)
- **3 Counselling Modes**: Learner, Parent & Guardian, and Joint Family Mode (side-by-side workspace)
- **8 Curated Vocational Trades** with NSQF Levels 3–6 progression pathways, salary & placement provenance badges, and callback request workflow
